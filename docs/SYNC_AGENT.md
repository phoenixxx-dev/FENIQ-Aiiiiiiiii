# عقد وكيل FeniqSync ← خادم فينيق (v1)

```
POST /v1/sync/catalog
Authorization: Bearer fsk_…            ← مفتاح الجهاز (يُنشأ من POST /v1/warehouses/{id}/tokens)
Content-Type: application/json
Content-Encoding: gzip                  ← اختياري ومُستحسن على إنترنت ضعيف
```

```json
{
  "source": "Amin",
  "warehouse_id": "WH-7",
  "generated_at": "2026-09-10T03:00:00+03:00",
  "mode": "full",
  "count": 655,
  "items": [
    {"item_id": "GUID-من-الأمين", "name_raw": "بنادول اكسترا", "price": 1250.5, "qty": 12,
     "barcode": "6210001", "unit_raw": "علبة"}
  ]
}
```

- `item_id` إلزامي وفريد. `price`/`qty` أرقام بلا فواصل ولا رمز عملة. أي حقل آخر يُحفظ كما هو.
- `count` يجب أن يساوي عدد `items` وإلا تُرفض الحمولة كاملة (حماية من الرفع المبتور).
- `mode`: `full` (افتراضي — الغائب يُعلَّم غير نشط) أو `delta` (الغائب لا يُلمس).

| الرد | المعنى | ماذا يفعل الوكيل |
|---|---|---|
| 202 | قُبلت مزامنة جديدة | يحذف الملف من طابوره المحلي |
| 200 + `duplicate:true` | وصلت سابقاً | يحذفه أيضاً (نجاح) |
| 401 | مفتاح غير صالح/ملغى | يتوقف وينبّه المستخدم — لا يعيد المحاولة |
| 409 | المفتاح مربوط بمستودع آخر | يتوقف وينبّه |
| 413 / 422 | حمولة كبيرة / غير صالحة | لا يعيد نفس الحمولة؛ يسجّل `message_ar` |
| 429 / 5xx / انقطاع | مؤقت | يعيد المحاولة لاحقاً بنفس البايتات (آمن — idempotent) |
